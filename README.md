# [My JavaScript package](https://github.com/aidken/my_js_pkg/)

This repository includes my javascript project scaffold I typically use.

I can use my external library of utility functions (like util_2.js). Try to
keep them in the Utils namespace. If you want you can introduce names into the
global scope, maybe by using destructuring assignment. If I want to use
import/export, that requires a server.

Tests gets run upon page load.

## External Libraries
Test suite: [Mocha](https://mochajs.org/)
Assert statement:[Chai](https://www.chaijs.com/)
CSV Parser: [Papa Parse](https://www.papaparse.com/)
